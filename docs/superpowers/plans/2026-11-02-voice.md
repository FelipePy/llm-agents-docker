# Voz do Jarvis (etapa 3a): plano de implementação

> Plano enxuto, a pedido do usuário (velocidade): tarefas, interfaces e testes. O código vai direto para os arquivos, com testes antes da implementação.

Spec: `docs/superpowers/specs/2026-11-02-voice-design.md`

## Tarefas

### 1. Worker Python (`app/voice`)
- `requirements.txt` (faster-whisper 1.2.1, edge-tts 7.3.1, onnxruntime, scipy, scikit-learn, tqdm, requests, numpy) e `requirements-nodeps.txt` (openwakeword 0.6.0, instalado com `--no-deps`: ele pede `tflite-runtime` no Linux, que não existe para Python ≥ 3.12; usamos ONNX).
- `setup.sh`: idempotente (carimbo com o hash dos requisitos); exige Python ≥ 3.10 e `venv`; baixa o modelo `hey_jarvis`.
- `jarvis_voice/protocol.py`: `encode`, `encode_json`, `read_message` (1 byte de tipo + 4 bytes big-endian + conteúdo).
- `jarvis_voice/segmenter.py`: `Segmenter.feed(frame, score) -> (started, segment|None)`; início com 2 quadros ≥ limiar, fim com 0,8 s de silêncio, mínimo 0,3 s de fala, máximo 30 s, pré-rolagem 0,3 s.
- `jarvis_voice/__main__.py`: loop de stdin; palavra de ativação sempre ativa (debounce 2 s); `listen`/`sleep`/`speak`/`cancel`; transcrição e síntese em threads.
- Testes (`unittest`, só biblioteca padrão): protocolo e segmentador.

### 2. Núcleo de voz no servidor (`app/server/src/voice/`)
- `protocol.ts`: `encodeFrame`, `encodeJson`, `FrameDecoder`.
- `text.ts`: `normalize`, `isGoodbye`, `stripMarkdown`, `SentenceSplitter`.
- `brain.ts`: `Brain`, `ClaudeBrain` (Agent SDK: `tools: []`, `settingSources: []`, `systemPrompt` próprio, `includePartialMessages`, `resume`, `env` sem `ANTHROPIC_*`), `brainEnv`.
- `session.ts`: `VoiceSession` (estados `off`/`preparing`/`sleeping`/`listening`/`thinking`/`speaking`, conforme a tabela do spec; reinicia o worker uma vez a cada 60 s).
- `worker.ts`: `WorkerProcess` (roda `setup.sh`, inicia `python -u -m jarvis_voice`, enquadramento, eventos).
- Tipos compartilhados em `types.ts`: `VoiceState`, `VoiceServerMessage`, `VoiceClientMessage`.
- Testes: texto, protocolo, cérebro (com `query` falso), sessão (worker e cérebro falsos), worker (Python falso feito em Node).

### 3. Canal `/ws/voice`
- `server.ts`: upgrade com token e `Origin`; uma sessão por vez (a nova substitui a antiga); binário → `audio`, texto → `client`.
- `main.ts`: `WorkerProcess` + `ClaudeBrain` (`LLM_AGENT_VOICE_MODEL`, padrão `haiku`; `cwd` na pasta de trabalho).
- Dependência `@anthropic-ai/claude-agent-sdk@0.3.316`.
- Testes: autenticação e ciclo `start` → `sleeping` com fakes.

### 4. Interface (`app/web/src/voice/`)
- `pcm.ts`: `Resampler`, `toInt16`, `FrameBatcher`, `rmsLevel` (testados).
- `capture.ts` (AudioWorklet), `player.ts` (fila de MP3, `AnalyserNode`, som de ativação), `client.ts` (`VoiceClient`).
- App: interruptor "Escuta ativa" (`llm-agent-voice`) e status no painel do dia; sinal do núcleo vindo da voz; legendas; `Esc` interrompe.
- README: seção de voz.
